Privacy Policy

Effective date: 2026-10-16

This policy applies to the Measured Sky publishing tool (the "Tool") and this website. The Tool is a private desktop application used only by the owner of the Measured Sky YouTube channel (@measuredsky) to manage that same channel. It is not offered to the public, has no other users, and has no user accounts of its own.

YouTube API Services. The Tool uses YouTube API Services. By using the Tool, users agree to be bound by the YouTube Terms of Service. Google's privacy practices are described in the Google Privacy Policy.

1. Google user data the Tool accesses, and why

When the channel owner signs in with Google, the Tool requests only the following scopes. Each is used only for the purpose listed.

ScopeDataPurpose
youtube.uploadAbility to upload videos to the owner's channelUpload finished Measured Sky videos with their title, description, tags, thumbnail and visibility.
youtube.force-sslManage the owner's YouTube videos, playlists, captions and related metadataEdit metadata of the channel's own videos, upload caption files, and set thumbnails and playlists.
youtube.readonlyRead the owner's channel and video metadataConfirm that an upload succeeded and read current video status and details.
yt-analytics.readonlyRead the channel's YouTube Analytics reportsRead performance figures (such as views and watch time) of the channel's own videos to evaluate and improve future videos.

The Tool does not request any Google data beyond these scopes.

2. How the data is used

Data received from Google APIs is used only to provide the user-facing features described above for the Measured Sky channel: uploading and managing the channel's own videos and reviewing the channel's own performance.

3. Storage and security

  • All data stays on the channel owner's own computer. The Tool has no server and no cloud database of its own.
  • The OAuth access and refresh tokens are stored in a local file on that computer, are never published or shared, and are sent only to Google.
  • Channel and analytics data read through the API is held locally only as needed and is deleted or refreshed within 30 days.

4. Sharing, selling and other uses

  • Google user data is not shared with, transferred to, or sold to any third party, advertising platform, data broker or reseller.
  • It is not used for advertising, including retargeting or personalized or interest-based ads.
  • It is not used to train, develop or improve generalized AI or machine-learning models.
  • It is not used to determine creditworthiness or for lending.
  • No person other than the channel owner reads the data, except where required for security, to comply with law, or with the owner's explicit consent.
  • This website uses no cookies, analytics or trackers.

5. Google API Services User Data Policy (Limited Use)

Measured Sky's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. Retention, deletion and revoking access

  • Revoke access at any time in your Google Account at https://myaccount.google.com/permissions (also reachable through Google security settings). After revocation the Tool can no longer access any Google data, and locally stored data from that authorization is deleted within 30 days.
  • Delete stored data: email measuredsky@gmail.com to request deletion; stored data is deleted within 7 days. Deleting data in the Tool does not affect data stored on YouTube.
  • Locally stored tokens and cached data are also removed when the Tool is uninstalled or its data folder is deleted.

7. Changes to this policy

If the way the Tool uses Google user data changes, this policy will be updated and the effective date changed before the new use begins.

8. Contact

Questions about this policy or your data: measuredsky@gmail.com.
